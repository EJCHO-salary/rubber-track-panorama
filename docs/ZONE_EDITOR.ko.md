# 영역 편집기

전개 사진을 만든 뒤 `/jobs/{id}/analysis`에서 영역을 직접 지정합니다. 백엔드는 자동 영역 분류 및 청크·티어 검출을 실행하지 않습니다. 경계 보조 선택은 사용자가 먼저 그린 다각형 주변에서 GrabCut으로 윤곽을 제안할 뿐이며, 사용자가 **닫힌 도형 저장**을 누르기 전에는 분류 데이터를 바꾸지 않습니다.

## 데이터 구조

- **분류 체계**: 형상별, 제조공법별 등 사용자가 이름을 정하는 최상위 레이어. 여러 체계가 같은 픽셀에서 겹쳐도 각각 독립적으로 보존됩니다.
- **세부 섹션**: 각 체계 안에 여러 개를 만들고 이름과 색을 수정할 수 있습니다. 트레드·골부 등의 초기 명칭은 예시입니다.
- **기본 섹션**: 한 체계에서 어떤 형상도 그리지 않은 픽셀을 채울 섹션. 처음에는 중립적인 '미지정'입니다. 기본 섹션을 변경할 수 있으며 마스크에는 빈 픽셀이 없습니다. 이는 미지정 픽셀을 자동 인식했다는 뜻이 아닙니다.
- **형상**: 하나의 세부 섹션에 속하는 다각형. 골부처럼 같은 섹션에 여러 형상을 둘 수 있습니다. `repeat=true`이면 `repeat_pitches`(1~2000)에 지정한 피치 간격마다 적용됩니다. 기본 `examples` 방식은 그린 도형들을 동일 패턴의 대체 예시로 취급해, 각 반복 구간에 가장 가까운 예시 **하나**를 적용합니다. 두 예시가 한 구간 안에 그려져 있어도 반복 밀도가 두 배가 되지 않습니다. 첫 번째 예시가 반복 위상의 기준이며 뒤에 그린 예시는 그 위상에 맞춰 배치됩니다. 한 주기에 여러 구성 요소가 필요하면 `independent` 방식을 선택합니다. `repeat=false`이면 그린 위치에만 적용됩니다. 같은 분류 체계에서 겹치는 형상은 목록에서 나중에 저장된 형상이 앞의 형상을 덮습니다.

점을 찍고 **첫 점을 다시 누르면** 도형이 닫힙니다. 다음 사진 클릭부터 같은 섹션의 다른 도형을 시작하므로 골부 여러 개를 한 번에 지정할 수 있습니다. 첫 점이 보이지 않으면 **현재 도형 닫기**를 누릅니다. 닫힌 도형은 사진 위의 점을 바로 끌어 수정하거나 우클릭으로 점을 삭제할 수 있습니다. 목록의 **점 추가**를 누르면 도형을 다시 열어 새 점을 넣을 수 있습니다. 저장된 도형의 편집 버튼도 닫힌 도형을 조정하는 상태로 엽니다. 편집 중 반복 간격을 바꾸면 아직 저장하지 않은 닫힌 도형 모두에 적용됩니다. 저장된 도형은 섹션별 일괄 간격 변경 기능을 사용합니다. 모든 도형을 닫은 뒤 한 번에 저장합니다. 편집 중에도 휠로 확대·축소할 수 있습니다. Ctrl+Z는 현재 열린 형상의 마지막 점 조작을 되돌립니다. 분류 체계와 섹션은 이름 수정, 추가, 삭제할 수 있습니다. 섹션 삭제 시 참조 형상도 지워지고 기본 섹션이 삭제된 경우 다른 섹션을 기본값으로 지정합니다.

## API 및 산출물

- `GET /api/jobs/{id}/zones`: v3 영역 문서 조회. 기존 전개 작업에는 최초 접근 시 편집 가능한 기본 체계를 생성합니다.
- `PUT /api/jobs/{id}/zones`: `{"groups":[...],"shapes":[...]}` 문서 전체 저장. 서버가 ID, 섹션 참조, 좌표, 반복 형상의 반복 간격 너비를 검증합니다.
- `POST /api/jobs/{id}/zones/assist`: `{"polygon":[[x,y],...]}`을 받아 제안 윤곽과 `changed`를 반환합니다. 저장은 하지 않습니다.
- `GET /api/jobs/{id}/zones/groups/{group_id}/overlay.png`: 해당 체계의 반투명 오버레이.
- `GET /api/jobs/{id}/zones/groups/{group_id}/mask.png`: 해당 체계의 픽셀 라벨. 각 체계의 `sections` 순서대로 1부터 부여합니다.

원본 좌표는 `panorama.png`를 기준으로 합니다. 마스크와 오버레이는 메모리 비용을 제한하기 위해 최대 약 200만 픽셀의 작업 해상도로 생성합니다. 응답의 `image_size_wh`, `pitch_px`, `nominal_pixels_per_mm`, `working_pixels_per_mm`와 `group_metrics`를 이용해 화면에 표시합니다. 면적 `mm²`는 정규화된 이미지의 명목 픽셀/mm를 사용한 추정값이며 실물 계측 보증값은 아닙니다.

반복 배치는 일정한 `pitch_px`를 더하는 대신, 사진 중앙의 반복되는 어두운 홀에서 실제 피치 기준점(`pitch_anchors_x`)을 측정하고 기준점 사이를 선형 보간합니다. 기준점 탐지가 불안정한 사진은 `pitch_anchor_source=nominal`로 표시하고 명목 피치 간격을 사용합니다. 측정 기준점과 반복 배치에는 영상의 손상 여부 또는 영역 명칭 추론이 개입하지 않습니다.

영역 산출물은 작업의 `result/zones/`에 저장됩니다. 작업 삭제 시 업로드 원본과 함께 지워집니다. 기존 손상 분석 문서의 사람이 그린 `zone_seeds`만 최초 초기화 시 옮깁니다. 자동 검출 후보와 자동 영역은 옮기지 않으며 기존 `result/damage/`는 갱신하지 않습니다. 앞으로 손상 분석을 추가한다면 사람이 확인한 v3 영역 문서를 입력으로 사용해야 합니다.
